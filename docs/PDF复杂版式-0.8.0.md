# PDF 复杂版式翻译 0.8.0

更新日期：2026-11-06。C++ / Qt Quick，Windows x64；在 0.7.0 原版式对照基础上增加多栏、表格结构校正和图片背景处理。

## 三阶段的实现范围

| 页面内容 | 当前处理方式 | 需要检查的地方 |
| --- | --- | --- |
| 两栏、三栏及跨栏标题 | 根据文字坐标与留白分区，每一区先读完左栏，再读右栏；译文限制在所属栏内 | 不规则图文环绕、窄栏与不明显的栏间距可能需要校正 |
| 有边框表格 | 提取矢量网格或检测扫描图中的线条，按单元格翻译，保留原线条 | 断线、斜线、嵌套表格不保证自动判断正确 |
| 合并单元格、多级表头 | 根据缺失的内部网格识别横向、纵向跨度；翻译带入表头与行标签 | 扫描页表头层数、识别原文和单位需要校对 |
| 无边框表格 | 根据多行对齐、紧凑内容、数字与表头特征推断 | 与普通分栏文字可能混淆，提供结构校正 |
| 跨页表格 | 匹配前页底部与后页顶部的列位置，继承表头语境；可手动关联前页 | 不移动页面或自动增加表头；多表格、不同列宽建议人工检查 |
| 图片上独立的 PDF 文字 | 删除原文字对象并放入译文，保留底下的图片或色块 | 与其他对象共享、旋转或无法独立替换的区域保留原文，可改用 AI 取字 |
| 扫描图中的文字 | 清理原文字，再叠加可搜索的译文文字层 | 纯色、渐变可自动清理；照片与纹理需选择背景处理方式 |

流程仍是「提取或识别原文 → 校对/复制 → 翻译 → 检查预览 → 导出」。识别不会自动开始翻译。页尺寸、页数和源文件保持；发生局部问题时，其余可处理区域仍可预览。

## 多栏与表格校正

打开 PDF 后点击 **结构校正**。扫描页需先识别文字。

- **文字区域**：选中段落，修改排版边界或阅读顺序；开启多选可合并相邻区域。拆分时填写上/左、下/右两部分原文，之后重新翻译。旧译文保留为草稿。
- **栏与单元格**：拖动选中区域的角点，或填写 X、Y、宽、高，再点击「应用边界」。边界不能切掉原文、越出页面或与相邻区域重叠；坐标单位为 PDF 点。
- **表格设置**：调整表头行数；填写前页页码关联表头，填 0 解除关联。程序寻找该页列数相同、已具有表头的表格。
- **撤销结构修改**：恢复当前页上一步结构操作。撤销记录仅在本次打开期间保留，最终结构会写入任务缓存。

合并要求阅读顺序连续，并位于同一栏或同一表格。不同单元格需组成矩形且选中全部内容。无边框单元格可合并；原表格线真实存在时，不允许把不同单元格合并成跨线译文，避免文字覆盖原线条。一个单元格里的多段文字可以合并。拆分不会绘制新的表格线。

原生 PDF 的拆分区域有时共享同一个原文字对象，关联区域须全部完成且能排下，才一起替换。放不下或数字不一致的单元格会标红；可以修改译文、字号与区域。数字变动如属有意修改，在段落校对中勾选「已核对单元格数字」。数值校验不能验证单位、语义或计算结果。

## 图片背景处理

扫描页点击文字区域，在段落校对窗口的「背景」中选择：

| 选择 | 效果与操作 |
| --- | --- |
| 自动清理纯色/渐变 | 从文字周围估计底色和变化，局部清除原文字；无法可靠处理时标出该区域 |
| 局部背景修复 | 在本机 CPU 上按相邻纹理补齐文字覆盖区域，不下载修复模型。先「保存并排版」，查看右页，再打开该区域勾选「已检查背景修复预览」，保存后可导出 |
| 底色译文框 | 用不透明色块覆盖该段原文字和译文区域，背景颜色可填 `#ffffff` 等；可选自动、深色、浅色字色 |
| 保留原图对照 | 该区域在预览和导出中保留原图；原文和译文仍可在校对窗口及整页文字中对照、复制 |

改动原文、译文、字号、字体、字色、区域或背景方式后，旧的修复确认失效。修复过程中无法可靠分离文字时，该块保留原图，其余区域继续预览；导出前需解决标记或选择保留原图。

**局部修复不是恢复被文字遮住的真实像素。** 细密纹理、物体边缘、人物、透明文字或文字与背景颜色接近时，可能出现痕迹和细节变化。复杂照片建议用底色框或原图对照。扫描路径会重建页面图像，保留外观而不保留原生矢量对象；并非无损图像编辑。

## 模型与性能

布局分析、文字定位与背景处理在本机运行，识图只发送文字区域图片给用户选定的视觉服务；翻译只发送原文与必要的表头/行标签。程序不自动切换云端，不修改服务设置和 llama.cpp 参数。

约 1～2B 的本地模型可以按短块识别、翻译；表格专名、数值、单位和文字较密的扫描页仍需校对。复杂结构由程序管理，模型无需输出整个页面的 JSON 坐标结构。

本机样例：Qwen3.5-2B 识别并翻译深色背景的两行英文约 8.6 秒；自定义服务 gpt-6.1-sol 处理含双栏、表格的 19 区域扫描页，识别约 77 秒、翻译约 58 秒。时间受模型、服务排队、网络和区域数影响，不是一般文档的性能保证。区域请求顺序执行，适用于单槽本地服务。

## 缓存与升级

缓存版本为 4，保存结构、阅读顺序、合并/拆分、原文与译文、表头关联和背景选择。原生页面须匹配新提取的原始版式指纹才能恢复整套结构；不匹配时仅尽量恢复与原文匹配的段落修改。0.6.0 整页文字草稿仍可复制，需重新识别坐标才能原位排版。缓存不包含 API Key。

从托盘退出旧版，运行 `build/Yiyi.exe`，或解压 `dist/Yiyi-0.8.0-windows-x64.zip` 后运行 `Yiyi/Yiyi.exe`。保留整个目录，尤其是 `ocr`、`pdf` 和两个 `yiyi_*_worker.exe`。运行无需安装 Qt 或 Python。

仍不保证任意 PDF 自动复刻：竖排、旋转、手写、复杂公式、不规则图文环绕、透视倾斜与嵌套表格需校对或保留原文。输入限制仍为 50 MiB、300 页，单块最多 16,000 字符。测试样例和未覆盖边界见 [验证记录](验证记录.md)。
