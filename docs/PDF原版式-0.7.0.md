# PDF 原版式翻译 0.7.0

更新日期：2026-11-06。适用于 Windows x64 的完整便携包。

## 结果与流程

普通文字 PDF 与扫描 PDF 都显示原文页、译文页，使用同一套排版结果进行预览和导出。译文保持原页尺寸及页数，在对应段落位置自然换行，保留图片、Logo、分隔线、项目列表与原有留白。中英文行数不必相同。

1. 导入 PDF；有文字层的页面可以直接翻译。
2. 扫描页先选择「识图」服务，识别当前页或指定范围。识别不自动开始翻译。
3. 点击右页区域，修改或复制原文；选择翻译服务并开始翻译。
4. 点击段落校对译文，支持单段重译、复制、保留原文、字号和排版区域调整。区域坐标单位为 PDF 点，72 点等于一英寸。
5. 导出 PDF，文字嵌入字体，可搜索、复制。源文件始终不被修改。

修改原文而未更新旧译文时，段落标记为待校对，导出会要求先重译或明确确认译文。清空译文或勾选「保留原文」会在该区域显示原文。翻译取消、失败和不完整结果不会覆盖此前的完整译文。

「整页文字」用于阅读和复制聚合文本，有区域数据时为只读，逐段修改请使用校对窗口。「框选」只生成独立识别结果，不自动替换整页。再次识别前的文字存入「旧稿」，方便找回之前的人工修改。

## 识别与排版

- 本机检测使用已随包提供的 RapidOCR 检测模型，只提取文字位置，不进行文字识别；未引入 Windows OCR。
- 所选视觉模型识别分区图片，程序根据行距、位置与文字外观合并段落。单行图像补白后发送，减少视觉编码器裁切窄图的问题。图像中的文字始终按待识别内容处理。
- 普通文字 PDF 读取已有坐标、字号、颜色、粗体与斜体信息。可传递段内强调，译文使用随包的 Yiyi PDF Sans / Serif 字体，不依赖电脑是否安装宋体。
- 扫描页按文字行清除背景，保留相邻的长线和图形组件，再叠加可复制的译文。模型识别为 Logo 或程序判断为图形文字的区域默认保留，用户可在校对窗口调整。
- 不翻译的完整网址、页码和标点区域保留原图。段内网址由翻译提示要求保留，导出前仍应校对。
- 排版使用原区域及可用空白，字号最多自动缩至原设置的 85%，通常不低于 8 点。仍放不下则标红并保留原文，阻止导出，避免截断或无限缩字。

## 范围与限制

首版针对白底、横排、单栏书页，包含标题、正文、列表、Logo 和分隔线。并排文字、多栏表格、竖排、手写、照片背景、复杂底纹与图文重叠不在自动重排保证范围。可用框选取字或保留原页。算法不能保证任意页面的像素级复刻；扫描页的译文页包含经过清理的原图背景，原生矢量内容仅在普通文字 PDF 路径保留。

原文识别和译文质量取决于所选模型、清晰度及语境。1～2B 本地模型可继续用于该流程，但专有名词、书名和长段语义仍需校对。程序不会自动切换云端模型，也不会更改模型服务器或个人服务配置。

输入限制为 50 MiB、300 页。扫描原文最多每页 32,000 字符、整篇 100 万字符；译文每页 64,000 字符、整篇 200 万字符，单段编辑上限 16,000 字符。识别范围逐页、区域请求逐个执行，适合本地单槽服务。截图质量标准为长边 1800 像素、高清为 2400 像素。

## 缓存与升级

缓存版本升级为 3，存储文字区域、识别原文、译文、编辑样式、保留状态及任务模型身份，不保存 API Key。普通 PDF 译文与源段落匹配后恢复。

0.6.0 扫描结果只有整页文字，缺少区域坐标。升级后保留为可复制草稿，重新识别后才能导出原版式译文；旧稿不会被错误塞入整页的一个区域。0.7.0 不再生成原图后附 A4 译文的导出方式。

## 验证与运行

验证覆盖原页尺寸与页数、图形位置、译文搜索复制、预览与导出一致、溢出阻止导出、原文编辑与单段重译、Chat / Responses 取消与失败恢复、区域/字号/保留状态缓存恢复，以及默认和最小窗口的交互。

另外用用户提供的两张参考截图裁出原文页，生成扫描 PDF 做视觉和实际模型验证；它们并非原始 PDF 文件。具体结果与局限见 [验证记录](验证记录.md)。

运行 `build/Yiyi.exe` 或解压 `dist/Yiyi-0.7.0-windows-x64.zip`。请保留整个发行目录，尤其是 `ocr`、`pdf` 及两个工作进程。构建依赖与字体哈希由 `scripts/setup-ocr.ps1`、`scripts/setup-pdf.ps1` 准备；应用运行不需要 Python。
