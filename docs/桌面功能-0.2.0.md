# 0.2.0 桌面功能与验证

日期：2026-11-05。环境：Windows x64、Qt 6.12.0、MinGW 13.1.0、Release 构建。

本文保留 0.2.0 的实现与验证记录。0.2.1 修复图标缩放质量，当前 0.3.0 继续提供这些桌面功能，并在托盘菜单增加截图取字；最新使用方式见 [使用说明](使用说明.md)，对应验证见 [验证记录](验证记录.md)。

## 使用方式

- 默认关闭窗口后留在托盘。点击托盘图标打开窗口，右键菜单可打开设置、暂停划词或退出。
- `Ctrl+Alt+Y` 打开工作台；`Ctrl+Alt+D` 查询其他应用中选中的文字。
- 拖动划选或双击选词后显示浮标，点击才查询。浮标不抢焦点，不自动请求模型。
- 「偏好设置 → 桌面与划词」可修改上述开关和快捷键。快捷键更改失败时保留原有注册，避免只更新了一半配置。
- 同一数据目录只运行一个实例，重复启动会唤回已有窗口。最小化、隐藏后的唤起保留最大化状态。

划词查询沿用当前模型、服务地址、思考等级、词典内容和目标语言，切换到智能识别模式。正在生成时拒绝额外查询，不中断旧请求，也不自动重试或转到其他模型。没有新增离线词库，也没有恢复此前取消的 LFM3 兼容工作。

## 实现

| 文件 | 职责 |
| --- | --- |
| `src/desktopintegration.*` | 原生托盘菜单、全局快捷键注册、鼠标选择手势、浮标生命周期及窗口恢复 |
| `src/selectioncapture.*` | Windows UI Automation 取词；独立子进程限制取词等待时间；显式快捷键的复制回退 |
| `src/singleinstance.*` | 按数据目录隔离的锁与本地唤起通道 |
| `qml/DesktopSettings.qml`、`ShortcutField.qml`、`UiSwitch.qml` | 桌面偏好及快捷键录入 |
| `qml/SelectionBubble.qml` | 不激活原应用以外窗口的划词浮标 |

自动划词优先读取鼠标所在控件，不依赖全局焦点遍历，也不使用剪贴板。控件所属进程、前台窗口、文字选择范围均需匹配；空内容或超过 24,000 字符时不查询。取词子进程只返回结果，不保存文本，超时会终止本次子进程。

快捷键取词优先读取前台线程对应的文字控件，再尝试 Windows 焦点接口。必要时在用户松开组合键后模拟 `Ctrl+C`，只接受本次复制的新文本。恢复原剪贴板格式前检查是否被其他应用覆盖。读取延迟提供的文本时，在剪贴板锁内完成读取，再记录最终序列号，避免把正常的延迟呈现误判为竞争。原剪贴板各格式合计超过 16 MiB 时取消复制回退，保留原内容。

快捷键录入只在设置窗口可见且激活时拦截按键，隐藏或切换到其他应用后恢复全局动作。0.2.0 同时修复了软件渲染后端下矢量图标滚出视口后仍显示的问题；该方案引入的小尺寸图标锯齿及线条不一致已在 0.2.1 修复，并保留滚动裁剪。

## 验证

测试均使用临时数据目录、合成文字、受控编辑器和本地模拟模型服务，没有读取用户 API Key、调用付费接口或重启模型服务。

- 核心套件：123 项通过。新增外部选择的空文本、长度限制、模式识别、生成期间拒绝重复请求及历史归属验证。
- 界面套件：覆盖快捷键录入、重复组合拒绝、保存、隐藏窗口后停止录入，以及最小窗口下的布局和图标裁剪。
- 桌面套件：25 项通过，覆盖真实 Windows 热键触发、注册冲突回滚、交换绑定、注销释放、托盘隐藏与恢复、UIA 读取、复制回退及富文本恢复、剪贴板竞争、密码框、过长内容、取消、划选及暂停、浮标点击后才提交请求、单实例唤起。
- Windows 独立进程：在仅保留系统目录的 PATH 下验证关闭到托盘、重复启动唤回已有窗口，以及关闭托盘选项后正常退出。日志为空。

核心、界面、桌面套件的最终明细分别见 `build/yiyi-core-results.xml`、`build/yiyi-ui-results.xml`、`build/yiyi-desktop-results.xml`。核心结果来自完整回归，后续只重跑受到修改影响的套件。汇总记录为 `artifacts/release-020-validation.json`；运行目录及压缩包检查记录为 `artifacts/release-020-package.json`。

原生鼠标测试需要可交互且未被遮挡的 Windows 桌面。排查中遇到当前会话的 RVLSession 遮挡及焦点竞争，也修正了测试编辑器拖动已有选择会进入拖放操作的用例设置；测试夹具已加入前台、遮挡和指针位置检查，环境不可用时明确跳过，避免向其他应用注入测试输入。上述 25 项的最终运行无失败、无跳过。

## 适用范围

系统划词取决于原应用提供的文字选择接口。浏览器、PDF 阅读器、管理员权限程序及自绘界面的兼容性需按实际应用确认；不提供选择接口时可尝试快捷键取词，或手动复制粘贴。0.2.0 当时不含 OCR，扫描版 PDF 和图片无法直接取词；当前版本可使用截图取字。尚未在第二台物理电脑上验证。

发布包新增 Qt Widgets 依赖以支持原生托盘菜单，主界面仍为 Qt Quick / QML。旧发行目录及旧 ZIP 保留，程序读取原有配置格式。
