# PDF 翻译 · 0.5.x

> 本文保留历史版本说明。当前 0.7.0 已统一为原版式翻译，扫描页不再附加 A4 译文页，详见 [0.7.0 说明](PDF原版式-0.7.0.md)。

本文记录 0.5.x 的文字页功能；0.6.0 已增加扫描页 AI 识别，见 [PDF 扫描件](PDF扫描件-0.6.0.md)。下文“不支持扫描件”指 0.5.x 原位置排版流程。

本版让简单 PDF 可以在原页面位置显示译文，左右对照阅读，并导出带可搜索文字的 PDF。适用 Windows x64，2026-11-06。

0.5.1 修复了超链接下划线被误判为图文重叠、列表标号被误判为多栏，以及浅灰色文本底框导致页面跳过的问题。编号、字母、罗马数字和常见项目符号保留原对象；浅色中性、无描边、轴对齐矩形在完全包住文字且位于文字下方时识别为底框，译文限制在框内。真正的多栏、图像重叠和未知形状仍按下述限制处理。

右页明确显示当前页是否有译文；未处理页数放在总进度开头，可译部分全部结束但仍有跳过页时显示「部分已完成」。重新打开原文件会重新识别版式，并恢复原文匹配的已保存译文。

## 支持范围

| 项目 | 本版行为 |
| --- | --- |
| 输入 | 本机未加密 PDF，有可提取的 Unicode 文字层；最多 50 MiB、300 页、100 万提取字符、5,000 个段落 |
| 版式 | 横排单栏；保留标题、正文区域、图片及矢量分隔线，保留大致字号、颜色、粗细及居中对齐 |
| 译文语言 | 简体中文、繁体中文、英语；主要面向英文资料译为中文 |
| 交互 | 原文 / 译文同步滚动、逐页浏览、125%～200% 放大、收起侧栏、段落校对及单段重译 |
| 进度 | 顺序翻译；完整段落落盘，停止 / 失败后续译；重新打开同一内容的文件可恢复 |
| 导出 | 嵌入字体的文字 PDF，支持复制与搜索；保留原页面尺寸，不覆盖源文件 |
| 无法容纳的译文 | 在原区域内换行并适度缩小字号；仍不合适则标红、保留原文、阻止导出并定位该页 |

扫描件、多栏论文、复杂表格、公式、竖排、倾斜文字、图文环绕、嵌套文字对象、非零裁切原点不在本版支持范围。检测到复杂结构时整页保留原样并解释原因；结构检测是保守启发式，不能保证识别所有复杂页面，导出前仍应检查。不同 PDF 的文字分组方式可能导致视觉上简单的页面也被保留。

不会保留所有原文字体、连字和段内混合样式；使用随包的开源中文字体排版。不自动新增页面、不跨段移动图片、不为扫描页调用 OCR。预览是页面图像，选中文字可打开校对弹窗，或使用导出文件的 PDF 阅读器。

## 工作流与数据

选择「PDF 翻译 → 打开 PDF」，先确认页面识别结果，再选择服务、目标语言、整篇 / 当前页并开始。打开文件不发送网络请求。翻译时仅把段落文字交给用户选定的现有 AI 服务，复用五种协议、认证和思考等级逻辑；工作台、TXT、识图与 PDF 请求互斥。

点击右页段落可以修改或重新翻译。清空译文恢复原文；重译失败保留上次完整译文。每段先收齐模型返回，再提交到页面，较长原段按约 1,000 字符拆分请求，整段完成才保存。单段译文上限 16,000 字符，失败不自动重复调用模型。

进度保存在应用数据目录的 `pdf-tasks/<SHA256>.json`，包含已译段落的原文、译文以及服务身份和语言设置，不包含 API Key。重新导入时先重新解析当前文件，仅对来源文字相同的段落恢复译文，不从缓存加载页面几何或对象编号。续译从服务配置中取当前凭据，并验证服务协议、地址、模型和思考等级仍匹配原任务。切换模型或语言请清除原任务后重新翻译。

部分翻译允许导出，界面会告知原文保留范围。导出前重新校验源文件指纹并检查全部页面。以临时文件写入后原子替换目标文件，溢出、源文件变化、写入失败时保留已有文件。

## 实现

- `PdfController` 管理任务队列、设置快照、缓存、段落编辑和工作进程生命周期；预览带页面 / 修订标识，避免旧结果覆盖新修改。
- 独立 `yiyi_pdf_worker.exe` 通过 JSON 文件接收解析 / 预览 / 导出任务，内含文字和布局，不含模型凭据。异常退出或 90 秒超时由主程序报告，可取消解析和导出。
- PDFium 提取字符、字体大小、颜色和文字对象位置，将行合并为段落；根据后续段落和图片 / 线条边界分配可用区域。数字页码和独立 URL 保留。
- Qt `QTextLayout` 计算换行和字号，`QPdfWriter` 生成带字体子集和 Unicode 映射的透明译文层，再通过 PDFium 合并。仅删除成功排版段落对应的原文字对象，保留原图片和矢量路径。
- 字号最多缩至原字号约 72%，通常不低于 7 pt；原文更小时不再缩小。无法排版或字体不支持的字符会提示修改，不静默截断。
- PDFium 二进制、源字体和构建工具按 SHA256 固定。`Yiyi PDF Sans` 为 Noto Sans CJK 的重命名 OFL 衍生字体，移除会干扰 PDF 文字反向映射的部首别名；避免中文复制成形似的康熙部首字符。运行时不依赖 Python。

## 验证

`tests/tst_pdf.cpp` 使用本机生成的两页文档，检查图片 / 分隔线像素保持不变、导出中文字符完整、源文件不变、溢出时保留原文和既有目标文件、修改后可重新导出、扫描 / 多栏 / 倾斜 / 图文重叠保留，以及取消、失败重试、配置快照和重开恢复。

`tests/tst_ui.cpp` 在 1000 × 680 与 900 × 600 下实际点击翻译、翻页、段落校对，验证放大和滚动，并导出 PDF。接口测试使用临时本机模拟服务，详细结果见 [验证记录](验证记录.md)。模型翻译质量取决于实际服务；这些测试不构成任意真实文档的版式或译文质量保证。
