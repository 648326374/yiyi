# PDF 扫描件 · 0.6.0

> 本文保留历史版本说明。当前 0.7.0 已统一为原版式翻译，扫描页不再附加 A4 译文页，详见 [0.7.0 说明](PDF原版式-0.7.0.md)。

适用 Windows x64。扫描页按「AI 识别原文 → 校对 / 复制 → 文本翻译 → 对照 PDF 导出」处理；文字页继续使用原有的原位置排版。

## 使用

1. 打开 PDF。导入、页面预览在本机完成，不会自动请求 AI。无可提取文字或大幅图片上仅有少量文字的页会提示扫描页；只有页码、水印的扫描件也可识别。页面分类是启发式，判断不合适时可以点右上角「AI 取字」，手动识别当前页。
2. 在「识图」栏选择支持图片的服务。它与「翻译」服务分别选择，可以使用同一个本地模型。llama.cpp 的视觉模型需加载匹配的 mmproj；服务配置中的「测试识图」可验证图片接口。
3. 点击「识别当前页」，或使用「批量识别」指定起止页。批量任务顺序处理范围内尚无识别原文的扫描页，自动跳过已有原文的页；重新识别已有内容用「识别当前页」。识别不会自动翻译。
4. 左侧保留原页，右侧「识别原文」可编辑、选择和复制。修改自动保存；看不清的文字可能标为 `[unclear]`，请对照原图校对。
5. 小字识别不理想时选择「高清」，或点击「框选」拖出文字区域。区域识别结果在独立弹窗显示，可修改、复制后粘贴到原文对应位置，不自动替换整页。
6. 选择翻译模型、目标语言及整篇 / 当前页，点击「开始翻译」。仅将已识别、校对后的文字发送给翻译服务。右侧切换到「译文」可编辑、复制或「重译本页」。
7. 修改原文后，旧译文保留并标记为「需更新」。可以重新翻译，或人工校对译文后点击「确认此译文」。含过期译文的文档不能导出；清空旧译文则允许作为未译页保留原图。
8. 点击「导出 PDF」。文字页保留现有版式；扫描原页后插入对应译文页，标题注明原文页码，长译文自动续页。原图、图表仍在原页中，译文可搜索、复制。导出不覆盖源文件。

## 中断与恢复

识别和翻译分别保存。停止识别、断流、空输出或图片处理失败均保留此前完整识别结果及编辑；当前未完成页面不算成功。重开相同内容的 PDF 会恢复原文、译文和任务设置。批量识别从未完成页继续；翻译重试保留旧译文，成功后才替换。

「重新翻译」清除译文和翻译任务设置，保留识别原文及校对，因此换翻译模型、语言无需再次识图。识图服务身份和识别清晰度按页记录；后续未识别页使用当前选择的识图服务。翻译服务沿用首次任务快照，切换前需要「重新翻译」。

缓存仍位于应用数据目录 `pdf-tasks/<文件 SHA256>.json`，新增扫描页原文、译文、过期标记及识图服务身份，兼容旧版文字页进度，不包含 API Key。页面几何与对象编号始终重新解析，不从缓存恢复。请注意缓存包含文档文字。

## 范围与资源限制

- 输入仍最多 50 MiB、300 页；目标语言为简体中文、繁体中文、英语。
- 识别图片按需渲染，标准长边 1800 像素、高清 2400 像素；框选区域单独按此清晰度渲染。沿用图片接口的 8 MiB PNG 限制，超过时提示调整清晰度或缩小区域。
- 每页识别原文最多 32,000 字符，扫描原文累计最多 100 万字符；每页译文最多 64,000 字符，扫描页译文累计最多 200 万字符。任务 JSON 不超过 32 MiB；导出最多 2,000 页。
- 每次只请求一页或一个区域；文字翻译按约 1,000 字符分段，每页完整完成才提交。和工作台、TXT、截图识图、连接测试互斥，避免向本地模型并发提交任务。
- 扫描页译文使用 A4 文本排版，不复刻扫描图内的字体、表格位置或公式结构；复杂表格、多栏、手写、模糊文字仍需人工校对。支持图片的模型不一定能可靠识别整页。
- 全部识别、翻译均使用明确选择的服务，不自动切换云端，不为 PDF 调用 Windows OCR 或 RapidOCR。

## 实现与验证

`PdfEngine` 负责页面分类、整页 / 局部渲染，以及将带字体与 Unicode 映射的译文页插入原页之后。`PdfController` 与 `pdfrecognition.cpp` 负责顺序请求、独立原文 / 译文状态、修改失效和恢复；识别提示词与截图 AI 取字共用。

`tests/tst_pdf.cpp` 覆盖扫描页含少量文字层、图片尺寸、可搜索中文续页、原图像素保留、过期译文阻止导出、Chat / Responses 分离模型、失败保留与重开续识别。界面测试实际操作识别、编辑、复制、翻译、框选与导出。记录见 [验证记录](验证记录.md)。

手动模型验证工具 `yiyi_pdf_scan_check` 不参与自动测试或发行包，默认仅接受本机回环地址，使用临时配置和显式提供的 PDF：

```powershell
cmake --build build --target yiyi_pdf_scan_check
.\build\yiyi_pdf_scan_check.exe sample.pdf http://127.0.0.1:8080/v1 '模型 ID' artifacts/local-scan-check
```

默认模式输出识别原文、译文、两个阶段耗时及对照 PDF，不读取已保存的个人服务或 API Key。仅在用户明确授权测试已有服务时，可使用 `--configured-provider 数据目录 服务名称 模型ID PDF路径 输出目录`；这个模式只读指定服务，将凭据保护后放入临时配置，结束后清理，不修改原设置、不记录凭据或接口地址。
