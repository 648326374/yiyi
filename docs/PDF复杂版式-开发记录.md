# PDF 复杂版式开发记录

目标：按已讨论的三个阶段完成实现、验证、编译及发行交付。基于 0.7.0，不缩减为单栏兼容补丁。

## 验收范围

1. 多栏、规则表格与独立背景文字：分区/分栏阅读顺序；栏内排版；网格单元格及表头上下文；数字校验；保留原网格/图片；局部失败不跳过全页。
2. 复杂表格与结构校正：合并单元格、多级表头、无边框表格、跨页表头关联；可视化栏边界及单元格合并/拆分/区域与阅读顺序修正；缓存与重新打开保留编辑；单元格溢出可定位处理。
3. 图片背景：纯色/渐变/纹理/照片文字区域的背景判别；可选局部背景修复、带底色译文框、保留原图对照；先预览再使用修复结果；浅/深文字颜色；原页及其他区域保持。

共有要求：C++/Qt Quick；本地 CPU 优先；不自动切换服务或更改个人配置；短块识别与翻译；取消/失败保留已校对数据；预览与导出一致，可搜索复制；源文件不变。复杂照片修复不承诺恢复被文字遮住的真实像素。

## 实施与证据

- 起点：检查现有源码和 0.7.0 交付；源代码基线备份在 `artifacts/complex-pdf-baseline`。
- 已加入 `pdflayout` 共用结构、原生及扫描多栏/表格、无边框推断、合并单元格与多级/跨页表头；表格上下文及数字变化检查。
- 已加入结构校正界面、区域边界、顺序、拆分、合并、单步撤销；共享原文字对象的拆分区域按组替换；缓存版本 4 保存修改及结构。
- 已加入 `pdfbackground` 的 CPU 局部修复与纯色/渐变清理，以及底色框/保留原图对照选项；修复需先预览后确认导出。纹理局部修复可能有痕迹。
- 首轮回归：`artifacts/complex-pdf-regression.txt` 46 项通过；`artifacts/complex-ui.txt` PDF 专项 8 项通过。背景清理专项 `artifacts/complex-background.txt` 8 项通过。后续修改仍需继续验证，不能视为最终交付结果。
- 实际渲染检查已修复扫描网格外框保护导致英文残留、字符墨迹间距导致数字被插入空格，以及文字基线被误认为装饰线的问题。验证图在 `artifacts/complex-pdf/stage1` 和 `stage3`。
- 后续边界与照片样例验证已完成；完整功能回归 300 项通过、3 项显式开关测试默认跳过。真实本地模型与已授权自定义服务样例成功导出。`build/Yiyi.exe` 已编译为 0.8.0。使用文档见 `PDF复杂版式-0.8.0.md`，最终记录见 `验证记录.md` 的 0.8.0 小节；发行核验及逐项审计存放在 `artifacts/080`。

三个阶段的功能、限制与操作均记入版本说明。测试通过仅证明其覆盖的范围；发行包核验以实际产物报告为准。

## 0.8.1 整书验证收尾

使用用户指定的 116 页 GLSL 技术书及已配置的「自定义服务 / gpt-6.1-sol」验证完整流程，修复真实文档暴露的嵌套文字、代码注释、目录、索引、图片标签、颜色与标点复制问题。最终核验 1,198 段实际写入的译文均可完整提取，页数/尺寸及源文件哈希保持。六页采用图像背景，蝴蝶图附近仍有轻微修补痕迹，不能视为无损重建。

最终 CTest 五套件通过，XML 合计 309 项通过、4 项因环境条件跳过、0 项失败。测试证据与便携包核验存放在 `artifacts/081`；整书译稿及逐页检查在 `artifacts/glsl-book`。版本说明见 [PDF 整书验证与修复](PDF整书验证-0.8.1.md)，具体统计和限制见 [验证记录](验证记录.md)。
