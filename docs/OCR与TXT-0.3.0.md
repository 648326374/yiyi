# 0.3.0 截图 OCR 与 TXT 文档翻译

日期：2026-11-05。平台：Windows x64、Qt 6.12.0、MinGW 13.1.0。

本页记录 0.3.0 的功能背景。其系统 OCR 实现已在 0.4.1 删除，当前截图使用方式请以 [使用说明](使用说明.md) 为准。

## 功能入口

- 工作台「截图取字」、托盘菜单「截图取字」，或窗口内 `Ctrl + Shift + S`。
- 左侧「文档翻译」，或窗口内 `Ctrl + 4`。
- 操作步骤、编码选择、暂停续译与导出限制见 [使用说明](使用说明.md)。

## 本地 OCR

截图由 Qt 按屏幕抓取，框选遮罩按各屏幕的逻辑坐标绘制，裁剪时按实际图像像素换算。多屏可选择其中任意一屏，暂不支持一次跨屏框选。开始框选前隐藏主窗口，完成或取消后恢复；`Esc` 和右键取消，不修改剪贴板。

当前 `OcrService` 使用独立的 C++ RapidOCR 工作者，已随发行包携带中英文模型；结果先进入可编辑的校对弹窗，用户点击翻译后才向所选服务发送文字。当前实现见 [截图识别与 AI 视觉](截图识别与AI视觉-0.4.0.md)。

快速取消后重新截图会使旧延时任务失效，防止重复遮罩或把遮罩截进新图片。

## TXT 处理

`DocumentController` 支持 UTF-8（可带 BOM）、UTF-16 LE / BE、GB18030 / GBK。自动模式只识别 BOM 或按严格 UTF-8 读取，不猜测旧编码；截断字节、无效 Unicode 和非文本控制字符会报错。导入最多 2 MiB、20 万字符、500 个需要翻译的段落，失败保留此前已加载的文档。

文本按原有换行拆分，长行优先在句子或空白边界切成最多约 1,000 字符的片段，不拆开 Unicode 代理对。空白无需请求模型。翻译复用现有 `AiClient` 协议适配，逐段顺序请求；开始前固定服务、凭据、模型、思考等级、语言和风格，中途修改配置不会改变任务归属。

每段收到完整成功响应后才提交到已完成译文。取消或失败清除当前段预览，保留先前段落；只有用户点击继续才重译当前段。不自动重试、改级、切换服务或转到云端。文档任务运行时阻止工作台及连接测试并发请求。

导出使用 `QSaveFile` 原子写入 UTF-8，统一模型返回的换行后按原文的 CRLF 或 LF 输出，拒绝覆盖原文。未完成任务可显式导出部分结果。任务不写入词典历史，不提供退出后的自动恢复，退出前需导出。

## 验证范围

测试使用临时配置、合成 TXT / 图片和本地模拟模型接口，不读取用户文档、个人凭据或调用实际 AI。覆盖编码读取与拒绝、文件限制、Unicode 分段、Chat Completions / Responses 顺序请求、配置快照、取消及断流续译、导出防覆盖、CRLF 处理，以及 100%、125%、150%、200% 截图坐标换算。

Windows 原生实测还覆盖合成图片 OCR、实际屏幕框选后识别、快速取消后重新框选、Esc 取消及主窗口恢复。界面测试覆盖默认及最小窗口的文档翻译布局、流式预览、导出状态和识别文字校对后使用。测试数量和发行包检查结果见 [验证记录](验证记录.md)。

识别效果受字体、清晰度、语言和版面影响；这里的验证不能保证任意图片或文档的识别、翻译准确率。没有调用真实模型验证长文翻译效果，也未在第二台物理电脑上验证。
