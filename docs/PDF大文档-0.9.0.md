# PDF 大文档处理 0.9.0

取消整份 PDF 的固定文件大小、页数、提取字符数和段落数限制。旧代码实际门槛为 50 MiB、300 页、100 万字符和 5,000 段；这些数字不再作为导入条件。可处理规模取决于页面复杂度、可用内存、磁盘空间和模型服务速度。

## 打开、翻译与恢复

打开时先校验文件并读取页数，再分批解析页面。首批页面完成后即可查看和校对，翻到尚未解析的页会优先处理该页。进度栏显示已解析页数；「暂停解析」保留已完成内容，「继续解析」接着处理剩余页。尚未解析的页会明确标注，不再被误报为无需翻译。

整篇翻译可以在后台解析期间启动，逐页加入后续发现的段落。跨页表格会等待前序表头信息；批量扫描识别也会等待尚未解析的页。识别和翻译仍按区域逐个请求模型，费用和耗时随内容增加，移除文件限制不会提升服务本身的速度。

每份文档在 `pdf-tasks/<文件指纹>.sqlite` 保存任务信息和各页内容。修改、翻译、结构校正按页保存；关闭后重新打开相同文件会复用已完成页面。旧 JSON 任务首次打开时迁移，旧文件保留，原文校对、译文、结构和背景确认按原文及版式指纹恢复。文件内容变化后按新文档处理，避免把旧译文套在新内容上。

「重新翻译」分批清除译文并保留原文与结构校正。清除期间可以取消暂停、继续清除；重新打开会恢复未完成的清除任务。

## 导出

导出前补齐未解析页面，未翻译的内容保留原文。界面显示导出进度，持续有进展的长任务不会被总时长超时中断；工作组件 90 秒没有进展时暂停并保留任务。

导出每 32 页保存为独立分片并释放该批页面资源，全部排版完成后按需读取图像流合成最终 PDF，避免把历史扫描图像持续积累在内存中。这会增加磁盘读写，目标磁盘应留出至少约两份输出文件大小的临时空间，并为复杂页面预留余量。暂存文件位于目标目录中的私有临时文件夹，成功后一次替换目标 PDF；取消或失败不会截断已有目标文件，也不会修改源 PDF。取消后可再次导出，已完成的翻译无需重做。

合成时只替换原页的内容和资源，保留页尺寸、目录书签、跨页链接及批注。标题和段落位置、图片、分隔线及可搜索的中文译文按现有版式规则处理。扫描背景重新编码后输出可能比原文件大，复杂背景仍需校对，不能保证任意图片文字都能无痕替换。原版式和背景处理操作见 [复杂版式说明](PDF复杂版式-0.8.0.md)。

## 仍保留的单页保护

不限制整篇总量，仍检查单页异常对象、嵌套深度、页面和渲染尺寸。原生页提取上限为每页 50,000 字符，单段编辑最多 16,000 字符；扫描识别原文每页最多 32,000 字符、译文每页最多 64,000 字符。过于复杂的页保留原文并说明原因，其余页面继续处理。
