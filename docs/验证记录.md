# 验证记录

## 0.11.3 Windows x64

使用 Visual Studio、Windows SDK 10.0.26100.0 和 Release x64 构建。使用临时配置、合成文档和本机模拟服务核验便携包。

- `scripts/build.ps1 -SmokeTest -Package` 构建并打包成功，启动检查通过。输出位于 `dist/Yiyi-0.11.3-winui-windows-x64.zip`。
- 原生回归测试通过 13 组，其中应用 7 组、PDF 6 组。测试覆盖 AI 协议、词典、设置和 SQLite 存储、原生图像处理、TXT、OOXML、PDF 任务恢复、文字层、页面结构、扫描与合并。
- 从解压目录启动，实测截图取字、文档打开、PDF 翻译和另存为。42 页测试文档完成分批导出，译文可搜索，源文件保持不变。
- PDF 测试验证无法安全替换的区域保留原文，并记录到问题清单。中断后可恢复任务，已有的译文可继续使用。

测试使用本机模拟服务验证请求和工作流程。桌面交互需要可操作的 Windows 桌面。 [构建和运行测试](../README.md#构建与测试)
