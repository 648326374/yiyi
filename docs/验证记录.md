# 验证记录

## 1.0.0 Windows x64

精简包和自带运行时包均在 Windows 10 22H2 专业版 x64 上构建并通过启动检查。解压自带运行时包后，确认程序属性与侧栏均显示 `1.0.0`，本机模拟服务收到的 User-Agent 为 `Yiyi/1.0.0`。

13 组原生测试和 2 组桌面用例全部通过。桌面用例从解压目录验证翻译工作台和本机 Word 的 DOCX 双栏预览。 [工作台截图](screenshots/translate-light.png)

浅色和 900 × 600 深色窗口均验证了文档页布局。TXT 的字数提示位于语言选项右侧，Word / PPT 未导入时显示打开文档和拖入提示。实测从打开入口导入合成 PPTX 并进入校对。整页预览的「内容联动」和「适合栏宽」均能完整显示。

### DOCX 整页预览

使用临时配置、本机模拟服务和合成文档。原文 3 页，译文 4 页，翻到原文第 2 页会定位到译文第 3 页的同一表格。实测了滚动联动、独立翻页、缩放、保存校对后的定位、预览取消及快速切换视图。浅色和深色均通过，深色使用 900 × 600 窗口。 [整页预览截图](screenshots/docx-preview.png)

原生回归覆盖预览副本、草稿隔离、取消清理、DOCX 导出及共享盘路径保留。LibreOffice 转换参数使用模拟程序验证，PDF 命名目标和缺少定位数据的处理使用合成 PDF 验证。配置 `YIYI_WORKBENCH_EXE` 后可运行 `office-preview-ui-smoke`。桌面用例使用本机 Word，未安装时由 CTest 标记为跳过。

## 0.11.3 Windows x64

使用 Visual Studio、Windows SDK 10.0.26100.0 和 Release x64 构建。使用临时配置、合成文档和本机模拟服务核验便携包。

- `scripts/build.ps1 -SmokeTest -Package` 构建并打包成功，启动检查通过。输出位于 `dist/Yiyi-0.11.3-winui-windows-x64.zip`。
- 原生回归测试通过 13 组，其中应用 7 组、PDF 6 组。测试覆盖 AI 协议、词典、设置和 SQLite 存储、原生图像处理、TXT、OOXML、PDF 任务恢复、文字层、页面结构、扫描与合并。
- 从解压目录启动，实测截图取字、文档打开、PDF 翻译和另存为。42 页测试文档完成分批导出，译文可搜索，源文件保持不变。
- PDF 测试验证无法安全替换的区域保留原文，并记录到问题清单。中断后可恢复任务，已有的译文可继续使用。

### 自带运行时包

`scripts/build.ps1 -SelfContained -SmokeTest -Package` 生成约 89 MiB 的 x64 ZIP。精简包和自带运行时包均通过构建与启动检查。

在 Windows 10 22H2 专业版 x64（19045.7807）上，将自带运行时包解压到含中文和空格的目录。以系统目录为工作目录启动后，确认程序加载了发行目录中的 `Microsoft.WindowsAppRuntime.dll`、`Microsoft.UI.Xaml.dll` 和 `Microsoft.UI.Xaml.Controls.dll`。实测浅色和深色启动、本机模拟翻译和历史保存、PDF 打开和翻页，以及合成图片的本地 OCR。

### 翻译工作台

在同一台 Windows 10 22H2 专业版机器上，从解压后的自带运行时包验证上下布局和最小窗口。原文栏的「截图取字」可打开框选，按 `Esc` 取消后保留原文。实测在偏好设置切换服务后，已有结果显示原模型，下一次请求使用新模型。 [浅色截图](screenshots/translate-light.png) · [深色截图](screenshots/translate-dark.png)

使用临时配置与本机模拟服务，验证 `Ctrl+V`、文本框菜单和「粘贴并翻译」各提交一次。选中的原文可被替换，粘贴后光标移到插入内容末尾。实测手动提交、旧配置下智能识别、空白或超长剪贴板、生成期间停止、打开历史，以及未配置服务时保留原文。

在可操作的 Windows 桌面上安装 `pywinauto`，并指定已构建的程序来启用 CTest 的工作台用例。用例使用前台窗口和剪贴板。

```powershell
$exe = (Resolve-Path build/winui-self-contained/Release/Yiyi.WinUI.exe).Path
cmake -S winui/tests -B build/winui-tests "-DYIYI_WORKBENCH_EXE=$exe"
ctest --test-dir build/winui-tests -C Release -R '^workbench-smoke$' --output-on-failure
```

### 内存复测

在同一台 Windows 10 x64 机器上使用 Release 构建、临时数据目录和本机模拟服务。内存以进程的私有工作集计量，冷启动及其托盘待机数据取三次运行的中位数。

| 场景 | 优化前（MiB） | 优化后（MiB） |
| --- | ---: | ---: |
| 干净启动后闲置 | 63.1 | 63.1 |
| 干净启动后收进托盘 | 63.3 | 63.2 |
| 首次显示并收起划词浮标后 | 79.4 | 64.3 |
| 打开设置、模拟翻译、两次划词，再打开文档页 | 95.8 | 79.9 |
| 查看 302 条测试历史后返回工作台，其中 300 条为长文本记录 | 101.2 | 73.3 |

首次收起划词浮标后，私有提交量也从 103.1 MiB 降到 86.8 MiB。实测了托盘唤回、划词浮标在两种主题下显示并点击查询、旧历史记录的搜索和收藏，以及从命令行打开 PDF、翻页并从偏好设置返回。

测试使用本机模拟服务验证请求和工作流程。桌面交互需要可操作的 Windows 桌面。 [构建和运行测试](../README.md#构建与测试)
