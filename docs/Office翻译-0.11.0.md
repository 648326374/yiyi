# Word / PPT 文档翻译

适用版本为 1.0.0。入口为「文档翻译 → Word / PPT」。直接处理 `.docx` / `.pptx`，另存结果仍可编辑。基本翻译、校对和导出无需安装 Office、LibreOffice 或 Python。

## 操作流程

1. 点击「打开文档」或拖入 DOCX / PPTX。导入、解析和预览在本机完成。
2. 打开「翻译设置」选择服务、语言和风格，再开始翻译。任务顺序处理，长段落拆为最多约 1,000 字符的请求。模型接收文字并返回译文。兼容现有本地和云端服务。
3. 选择「逐段校对」查看和修改段落。可保存校对、保留原文或单段重译。重译成功后才替换旧译文，失败或取消时保留已有结果。
4. 暂停后可继续。进度按源文件内容指纹保存到应用数据目录 `office-tasks/`，重新打开同一原文件可恢复。未提交的校对草稿也会保存；更换文档前可取消、直接更换或导出后更换。
5. 「另存译文」生成新的同格式文件，并附带 `<译文文件名>.issues.txt` 校对清单。未完成、自动域、修订及不支持的内容保留原文。原文件不能被译文覆盖。

续译沿用原任务的模型、语言和风格。恢复任务后，「翻译设置」显示该任务实际使用的选项。更改源语言、目标语言、风格或服务时，会先提示清除旧译文及校对草稿。取消保留原任务，确认后再点击「开始翻译」按新设置重译。需要保留旧结果时，请先取消并另存译文。

重新启动后，如果原服务的地址、协议、模型或思考等级已变化，程序会要求恢复配置，或清除当前译文后重新开始。缓存不保存 API Key。已缓存的任务需要明确切换目标语言后重译。

全部段落完成后，主按钮变为「另存译文」。可在「更多文档操作」中选择「重新翻译」，确认后清除旧译文和草稿，并按当前设置从第一段开始。取消会保留当前任务。

## 内容与版式

| 内容 | 当前行为 |
| --- | --- |
| Word 正文、标题、列表、表格 | 按段落或单元格中的段落翻译，保留样式、编号和合并关系 |
| 页眉、页脚、脚注、尾注 | 翻译普通文字；页码、目录等自动域保留 |
| PPT 文本框、分组内文字、表格、备注 | 按幻灯片和段落校对，保留对象位置、背景、图片及动画关系 |
| 图表 | 翻译富文本标题；与工作簿关联的系列名、分类、数据和嵌入工作簿保留，列入清单 |
| SmartArt | 翻译包内文字和绘图缓存，保留图形关系；文字变长后应检查实际布局 |
| 图片 | 保留原图；「图片取字」可手动使用 AI 识图或本地 OCR，复制、校对后单独翻译，不自动改写原图 |
| 自动域、修订和嵌入文件 | 保留原样并提示；建议先在 Office 中处理修订，再导入 |

Word 的译文长度会改变换行和分页，不保证页数或逐行位置一致。段内多种样式、超链接的文字按长度映射回原来的文本片段，程序会提示检查加粗、颜色或链接文字的范围。

自动翻译时，识别出的 Windows 共享盘路径原样保留。路径中包含逗号等句读时，可用引号标明路径范围。校对清单会提示已有译文中可能被改动的路径。

PPT 可选择在字号下限内缩小文字，默认下限 12 pt，原本更小的文字不会被放大。仍可能溢出的文本框会提示校对，译文不会因此被删减。溢出检查是字体测量估算，不能替代实际 Office 排版。

## 图片取字与页面预览

「更多文档操作 → 图片取字」列出包内媒体资源。选择后打开图片校对窗口，默认 AI 识图模式，点击开始识别才请求所选视觉模型，也可切换本地 OCR。WMF、EMF 等当前图片解码器不支持的格式，可在 Office 中截图后识别。

- 打开 DOCX 时，有可用排版器就进入「整页预览」。左栏是原文，右栏是已保存的译文，两栏显示各自的实际页码。默认「内容联动」，翻页或滚动时按同一正文段落定位，表格也按对应行中的段落定位。可切换「独立翻页」，也可选择适合栏宽、适合整页或放大。
- 当前页缺少可对应的正文位置时，另一栏会停在原处。排版器未提供可用的定位数据时，使用独立翻页。
- 翻译完成后会更新整页预览。保存校对后切回整页预览可查看重排后的版面，也可用「刷新预览」重建。切换视图和刷新预览会保留尚未保存的校对稿。
- DOCX 可用本机 Word 排版，也可从「更多文档操作」选择已安装的 LibreOffice `soffice.exe`。整页预览使用临时副本，本机没有排版器时可使用「逐段校对」。PPTX 可从同一菜单用 LibreOffice 生成 PDF 版式预览，再用 PDF 阅读器打开。

## 文件范围

支持单个不超过 512 MiB 的 DOCX / PPTX，单个 XML 部件最多 32 MiB。旧版 DOC / PPT 请先另存为新格式；密码加密、数字签名和含宏的文档需先保存为普通未签名副本。文档不会整份上传，只有翻译段落或用户主动选择识别的图片发送给配置的服务。

`office-smoke` 和 `office-task-smoke` 使用合成译文验证 OOXML 读写、任务恢复和导出。示例文件位于 `tests/fixtures/office/`。 [验证记录](验证记录.md)
