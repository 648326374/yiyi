# Word / PPT 文档翻译

版本：0.11.2（初版 0.11.0）。入口为「文档翻译 → Word / PPT」。直接处理 `.docx` / `.pptx`，另存结果仍可编辑；基本翻译、校对和导出无需安装 Office、LibreOffice 或 Python。

## 操作流程

1. 打开或拖入一个 DOCX / PPTX。导入、解析和预览在本机完成，不请求模型。
2. 选择翻译服务、语言和风格，开始翻译。任务顺序处理，长段落拆为最多约 1,000 字符的请求；模型只接收文字，不生成 XML。兼容现有本地和云端服务。
3. 左侧选择段落，右侧核对原文与译文；可保存校对、保留原文或单段重译。重译成功后才替换旧译文，失败或取消时保留已有结果。
4. 暂停后可继续。进度按源文件内容指纹保存到应用数据目录 `office-tasks/`，重新打开同一原文件可恢复。未提交的校对草稿也会保存；更换文档前可取消、直接更换或导出后更换。
5. 「另存译文」生成新的同格式文件，并附带 `<译文文件名>.issues.txt` 校对清单。未完成、自动域、修订及不支持的内容保留原文。原文件不能被译文覆盖。

续译沿用原任务的模型、语言和风格。恢复任务后，顶部控件显示任务实际使用的设置，与底部说明一致；其他页面的语言或服务选择不会改变已有任务。更改源语言、目标语言、风格或服务时，会先提示清除旧译文及校对草稿；取消保留原任务，确认后再点击「开始翻译」按新设置重译。需要保留旧结果时，请先取消并另存译文。

重新启动后，如果原服务的地址、协议、模型或思考等级已变化，程序会要求恢复配置，或清除当前译文后重新开始。缓存不保存 API Key。0.11.1 修复了旧版控件显示新选择、实际请求仍沿用旧任务语言的问题；已缓存的中文任务不会自动转换为英文，需要明确切换设置后重译。

全部段落完成后，主按钮显示「重新翻译」并保持可点击。先确认再清除译文和草稿，按顶部显示的设置从第一段开始；取消不会修改当前任务。更换目标语言时先选择新语言并确认切换，主按钮会恢复为「开始翻译」。

## 内容与版式

| 内容 | 当前行为 |
| --- | --- |
| Word 正文、标题、列表、表格 | 按段落或单元格中的段落翻译，保留样式、编号和合并关系 |
| 页眉、页脚、脚注、尾注 | 翻译普通文字；页码、目录等自动域保留 |
| PPT 文本框、分组内文字、表格、备注 | 按幻灯片和段落校对，保留对象位置、背景、图片及动画关系 |
| 图表 | 翻译富文本标题；与工作簿关联的系列名、分类、数据和嵌入工作簿保留，列入清单 |
| SmartArt | 翻译包内文字和绘图缓存，保留图形关系；文字变长后应检查实际布局 |
| 图片 | 保留原图；「图片取字」可手动使用 AI 识图或本地 OCR，复制、校对后单独翻译，不自动改写原图 |
| 自动域、修订和嵌入文件 | 保留原样并提示；建议先在 Office 中处理修订，再导入 |

Word 的译文长度会改变换行和分页，不保证页数或逐行位置一致。段内多种样式、超链接的文字按长度映射回原来的文本片段，程序会提示检查加粗、颜色或链接文字的范围。

PPT 可选择在字号下限内缩小文字，默认下限 12 pt，原本更小的文字不会被放大。仍可能溢出的文本框会提示校对，译文不会因此被删减。溢出检查是字体测量估算，不能替代实际 Office 排版。

## 图片取字与页面预览

「图片取字」列出包内媒体资源。选择后打开图片校对窗口，默认 AI 识图模式，点击开始识别才请求所选视觉模型；也可切换本地 OCR。WMF、EMF 等当前图片解码器不支持的格式，可在 Office 中截图后识别。

应用内默认展示段落对照。需要整页预览时，可在文档选项选择已安装的 LibreOffice `soffice.exe`，生成临时 PDF 后打开。转换使用独立临时配置目录，不替换原文件，不使用个人 LibreOffice 配置；不同软件和字体可能产生版式差异。LibreOffice 不随发行包提供。

## 文件范围

支持单个不超过 512 MiB 的 DOCX / PPTX，单个 XML 部件最多 32 MiB。旧版 DOC / PPT 请先另存为新格式；密码加密、数字签名和含宏的文档需先保存为普通未签名副本。文档不会整份上传，只有翻译段落或用户主动选择识别的图片发送给配置的服务。

开发验证工具 `yiyi_office_check` 使用合成译文检查读写往返，不调用模型。原生 Office 检查见 `tools/check_office_native.ps1`；示例文件由 `tools/make_office_fixtures.py` 生成，测试数据和个人配置不放入发行包。
