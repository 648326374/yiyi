# PDF 整书验证与修复 0.8.1

0.8.1 根据一本 116 页 GLSL 技术书的真实翻译结果，改进嵌套文字、代码、目录、索引及图中标签的处理。多栏、复杂表格与背景校正的操作仍见 [0.8.0 说明](PDF复杂版式-0.8.0.md)。

## 修复内容

- 读取和替换嵌套 Form 中的文字，并使用完整变换计算字号。修改某页时不改动其他页面共用的原对象。
- 修复破折号、全角斜线等标点的搜索/复制映射。准备字体时为 Unicode 别名分配独立字形 ID，排版时关闭会改变对应字符的连字与替换。
- 检测到当前 PDF 后端无法完整重写的渐变着色对象时，以图像保留该页背景并提示用户；译文仍为可搜索文字，原生矢量和未替换文字的搜索性可能不再保留。
- 背景图像回退显示为提示，不再误报整页未翻译；混合文档按可译段落显示进度，只有网址等无需翻译的页面不再使整书进度看起来缺页。
- 导出时保留白色底框与彩色图形，避免 PDF 色彩空间重写导致白框变黑；收紧矢量边界，减少把正文误认为与图形重叠。
- 分开相邻流程图标签，识别窄框中的纵向逐字标签。目录及索引的小字号区域、同排页码和细线边距更准确。
- 代码段整段发送，仅翻译注释；保留标识符、字面量、运算符和预处理指令。校验区分代码 token 边界，防止把两个名称合并成一个。代码中的英文使用等宽字体，中文注释使用随包字体回退。
- 区分排版换行的注释、真实代码行以及用等宽字体印刷的说明文字。自动推断仍有边界，用户应检查代码与原文对照。
- 字母索引按栏、逐条处理，不把索引当成无边框表格，不合并相邻条目；字母标题、引用页码保留。数字检查支持中文与数字直接相连。
- 混合页面在已有原生文字块及其对应关系时，先隐藏准确对应的原文字对象再生成扫描背景，减少页眉重影和分隔线被擦除。图片内的文字仍使用局部清理或背景修复。
- 浅色文字在橙色等背景上的定位与背景判断得到改进；扫描块译文与原文一致时保留原始像素。

## 整书样例的范围

测试使用用户指定的《GLSL Essentials》及已配置的「自定义服务 / gpt-6.1-sol」，沿用服务中的 low 思考等级。使用生产 PDF 控制器调用服务，在临时配置中运行，完成进度持续保存；不修改个人服务、API Key 或 llama.cpp 参数。

正文、标题、目录、索引及代码注释翻译为中文；程序标识符、数值、公式、网址、作者署名和出版商标识保留。图中嵌入的自然语言标签另外识别、校对和排版，保留变量与坐标。少量长段落和术语经过人工校对，以适应原版区域。

这份样例包含封面扫描路径，以及四页补充图片标签的混合页面。另有一页出版商 Logo 含渐变着色对象，使用上述背景回退。共六页重建页面图像并叠加可搜索的中文；其余页面按原生对象替换。扫描路径中的未替换代码、署名等可能只有原图像素，不能据此承诺整书所有原始对象、文字及矢量均无损保留。

蝴蝶图片标签采用局部背景修复，预览检查后确认；附近纹理仍可见轻微修补痕迹。此测试不代表任意照片、公式、表格或模糊扫描件都能自动准确处理，也不等于出版级翻译审校。

原书及其译稿属于用户的本地测试材料，不收入软件发行压缩包。进度、逐页渲染及审计记录保存在源码工作区的 `artifacts/glsl-book`，便携包不包含个人配置、凭据或整书缓存。

最终译稿为 `artifacts/glsl-book/GLSL-Essentials-简体中文.pdf`。116 页的尺寸核验通过，实际替换的 1,198 段译文均能完整提取，原生路径页面的图片位置和像素摘要保持，源 PDF 哈希不变。这些检查验证完整性与排版输出，不替代翻译语义审校。最终回归为 309 项通过、4 项按环境条件跳过、0 项失败，详情见 [验证记录](验证记录.md)。

## 更新和使用

从托盘退出旧版后运行 `build/Yiyi.exe`，或解压 `dist/Yiyi-0.8.1-windows-x64.zip` 后运行其中的 `Yiyi/Yiyi.exe`。保留整个目录；不需要安装 Qt 或 Python。

重新打开 PDF 才会使用新版提取结果。已有翻译按缓存中的原文与结构匹配恢复；结构变化的段落需要校对或重译。恢复旧项目后应查看未完成区域和导出提示，不能只凭完成数量判断整份文档质量。
