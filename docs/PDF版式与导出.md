# PDF 版式与导出

导入后可在「翻译设置」选择翻译模型、扫描页识图模型和清晰度。在主工具栏选择当前页或整篇翻译，原文和译文在两页同步预览。点击右页的段落可修改原文、译文、位置、字号及样式。操作入口和任务恢复见 [使用说明](使用说明.md#pdf-翻译)。

## 页面分析与结构校正

| 页面内容 | 处理方式 |
| --- | --- |
| 横排文字、多栏及跨栏标题 | 使用文字坐标与留白判断阅读顺序，在对应区域重新排版 |
| 有边框表格、合并单元格、多级表头 | 按网格识别单元格和跨行跨列跨度，利用表头与行标签辅助翻译 |
| 无边框表格 | 根据多行的对齐关系推断结构，可在校对时修正 |
| 跨页表格 | 可关联同列数的前页表格，翻译时继承表头语境 |
| 扫描页 | 本机检测文字区域，由所选视觉模型识别各区域，再排版可搜索的译文 |

在「更多 → 结构校正」可调整阅读顺序、栏与单元格边界及表头，或合并连续的区域。边界坐标用 PDF 点表示，72 点等于一英寸。拆分时填写两部分原文，原译文保留为草稿。共享同一原文字对象的段落需要一起排版成功才能替换。表格数字有变动时，在段落校对中检查数字，修改译文或确认变动后再保存。

## 扫描页背景

在段落校对窗口选择背景处理方式。

| 方式 | 效果 |
| --- | --- |
| 自动清理纯色/渐变 | 从文字周围估计颜色，局部清除原文字 |
| 局部背景修复 | 参照周围纹理填补文字区域。保存后先检查右页，再打开段落并确认修复预览 |
| 底色译文框 | 使用不透明底色覆盖原文字，底色可填入 `#ffffff` 等 RGB 颜色 |
| 保留原图对照 | 导出该区域的原图，仍可在校对窗口查看和复制译文 |

修改译文、区域或背景处理设置后，需要重新检查局部修复。复杂照片、纹理和物体边缘可能留下修复痕迹。竖排、旋转、手写、复杂公式和不规则图文环绕也需要人工检查。

## 任务恢复和导出

每份文档按内容指纹保存至应用数据目录的 `pdf-tasks/<文件指纹>.sqlite`。重新打开同一原文件可查看已有进度、继续已暂停的任务。旧的 JSON 任务可以导入。任务保存服务身份和设置，API Key 仍由应用的服务配置管理。

导出分批处理页面，在目标目录创建临时文件。完成后替换目标，失败或取消时保留原 PDF 与已有目标文件。目标磁盘需要同时容纳导出分片和最终文件。合成保留页尺寸、目录书签、跨页链接及批注。PDF 字体随包提供，导出译文可以搜索、复制。

未翻译或无法安全替换的内容保留原文。导出检查发现问题时，同目录的 `<文件名>.pdf.issues.txt` 列出页码、段落和原因。可从「待校对」定位修改，随后重新导出。

单页复杂度、提取和渲染仍有保护上限。原生页最多提取 50,000 字符，单段编辑最多 16,000 字符，页面原文和译文分别限 32,000 与 64,000 字符。 [验证记录](验证记录.md)
