# PDF 界面与流程 0.10.0

## 实施范围

- 两行工具栏、双页阅读区、一行状态栏；模型和识别质量收进翻译设置，高级功能收进更多。
- 页码输入跳转；点击段落校对；未处理使用普通提示，待校对使用橙色，失败使用红色。
- 文字页直接翻译，扫描页自动识别后翻译；统一暂停、继续，保存范围和处理位置，重开后由用户继续。
- 全书统计按页列出未处理、待校对原因；不清晰文字、原文变动、排版和背景问题可以定位到段落。
- 当前页重译暂存新结果，整页成功后一次替换；失败、暂停不覆盖已有译文，不影响其他页。清空全书译文单独确认。
- 保留原模型快照、分页缓存和原版式导出；不读取用户凭据、不调用真实模型服务进行测试。

## 使用方式

- 主工具栏默认为当前页。选择整篇文档后，文字页直接翻译，扫描页按页识别并自动翻译。
- 运行时点「暂停」，重开文件后点「继续」。继续的范围与模型沿用原任务，不受当前阅读页码或工作台模型切换影响。
- 点击底部统计展开文档进度，选择页码，再点击不清晰文字、原文变动、排版或背景问题进入段落校对。
- 「更多 → 重译当前页」沿用该文档的翻译模型，全部结果成功后一次替换。暂停期间修改页面内容会使暂存结果失效，继续时重新生成。
- 「更多 → 清空全书译文」另行确认，可在清空后更换任务模型与语言。高级识别、框选、结构校正、整页文字和阅读模式也在「更多」中。

## 保存方式

SQLite 任务元数据增加任务种类、范围、游标、状态、识图模型身份和当前页重译暂存结果，不包含 API Key。读取运行中断的任务时改为暂停，等待用户继续。重译页提交和清除暂存任务使用同一数据库事务；未完整的识别页不写入已完成内容。

页摘要增加问题类型和待校对段数。旧任务每批最多读取 8 页补齐摘要；列表使用摘要，选择页面后才读取段落详情。升级后的任务使用存储版本 6，请用 0.10.0 或后续兼容版本继续打开。
