# 译意 · AI 翻译词典

适用版本为 **0.11.3**（Windows x64）。

安装 Windows App Runtime 2.4 x64，解压发行 ZIP，打开 `Yiyi-WinUI` 文件夹并双击 **Yiyi.WinUI.exe**。请保留整个文件夹。 [Windows App Runtime 下载](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads/)

升级时请先右键托盘图标「退出译意」，再打开新版本；仅关闭窗口通常仍在后台运行，再次启动会唤回已有进程。

支持文字 PDF 版式翻译与扫描页 AI 取字、校对、翻译和对照导出。本地截图统一使用 RapidOCR；另可选择 AI 识图取字，配置时支持真实图片能力测试。保留 TXT 翻译、托盘、全局快捷键和划词浮标。请保留发行包中的 `ocr`、`pdf` 目录及两个 `yiyi_*_worker.exe`。

## 第一次使用

1. 点击左侧「偏好设置」→「添加 AI 服务」。
2. 选择服务预设，填写或核对服务地址、模型名称和 API Key。
3. 点击「测试连接」。测试会向该模型发送一条简短请求，云端服务可能计费。
4. 保存服务，回到「翻译工作台」开始使用。

启动时展示的 `serendipity` 是明确标注的内置排版示例，未发送网络请求。示例可复制，但不会自动写入历史，也不能直接收藏。

## 本地 AI

翻译和 AI 识图连接你已启动的模型服务，不内置大语言模型。独立的本地 OCR 则自带轻量文字识别模型，可直接使用。

| 服务 | 协议 | 示例地址 | 模型名称 |
| --- | --- | --- | --- |
| Ollama | Ollama 原生 | `http://localhost:11434` | 使用 `ollama list` 中已经下载的完整模型名称，例如 `qwen3:8b` |
| LM Studio | OpenAI Chat Completions | `http://localhost:1234/v1` | 在 LM Studio 的 Developer 页面启动服务，填入服务实际暴露的模型 ID |
| llama.cpp | OpenAI Chat Completions | `http://127.0.0.1:8080/v1` | 使用 `/v1/models` 返回的 ID，例如 `Qwen3.5-0.8B-Q4_K_M.gguf` |

模型必须先在相应工具中下载、加载或启动。本地服务通常不需要 API Key。如果服务运行在其他电脑，填写那台电脑的局域网地址和实际端口。

llama.cpp 与 Ollama 的接口不同；`llama-server` 应选择 OpenAI Chat Completions，选择 Ollama 原生会请求错误的 `/api/chat` 路径。

## 云端与自定义服务

内置 OpenAI Chat Completions、OpenAI Responses、DeepSeek、通义千问、Claude、Gemini 的配置预设；支持创建多个服务，并在工作台顶部切换。

- 支持 `/chat/completions` 的 OpenAI、DeepSeek、通义千问及兼容服务选择「OpenAI Chat Completions」（旧版名称为「OpenAI 兼容」）；通常填写以 `/v1` 结尾的 API 基础地址。
- 使用 `/responses` 的服务选择「OpenAI Responses」。基础地址可填写 `http://主机:端口/v1`，程序会请求 `/v1/responses`；也接受完整的 `/v1/responses` 地址。此协议支持连接测试、流式翻译和查词。
- Claude 选择「Anthropic」，Gemini 选择「Gemini」。不同协议不能只靠修改地址互换。
- 模型 ID 必须是你的账户或服务器可用的真实名称。预设模型可修改，不保证每个账户均有权限。
- OpenAI Chat Completions 也接受完整的 `/chat/completions` 地址；不接受带查询参数、用户名、密码的地址。切换 Chat Completions / Responses 协议时，已有完整端点会替换为对应端点。
- 程序遵循 Windows 系统代理设置。地址和 API Key 不同于网页端登录地址和密码。
- 编辑已有服务时，API Key 留空保留原凭据；填入新值会替换，勾选清除则移除凭据。切换服务预设时，会清除旧服务的凭据，避免误用。

如果看到 `codex channel: /v1/chat/completions endpoint not supported`，这表示所选端点不受服务端支持。把「接口协议」改为 **OpenAI Responses** 后重新测试，原地址、模型名称和已保存的 API Key 可以保留。程序不会自动切换协议或重复提交请求。

## 思考等级（可选）

在「偏好设置 → 添加 / 编辑 AI 服务」中，模型名称下方可设置思考等级；窗口较小时向下滚动即可看到。此选项仅在 **OpenAI Responses**、**OpenAI Chat Completions** 协议下显示，兼容接口也可使用，但不代表所选模型支持所有等级。

| 选项 | 行为 |
| --- | --- |
| 跟随服务（默认） | 完全不发送思考等级参数，由服务按自身默认行为处理。旧配置也使用此选项。 |
| 关闭思考 · `none` | 显式请求关闭思考；仍需要模型和服务支持，不等于省略参数。 |
| 低 · `low` / 中 · `medium` / 高 · `high` | 请求相应等级；低等级通常有利于缩短等待时间，实际耗时取决于模型、服务负载和网络。 |
| 很高 · `xhigh` / 最高 · `max` | 请求更高思考等级；只应在模型明确支持时选择，可能增加耗时和用量。 |

不支持思考等级的本地模型、或不确定支持情况的兼容服务，请保持 **「跟随服务」**。程序不会根据模型名称自动启用或推断支持的等级。GPT-6 Luna 用于日常查词时可先尝试 `low`，再通过「测试连接」确认你的服务接受该设置；测试通过不代表服务一定实际执行了所选等级。

GPT-6.1 Sol 用于日常查词时，建议先对比 **低 · `low`** 的速度与质量。其官方支持等级从 `low` 开始，不支持 `none`，默认是 `medium`；更高思考等级通常增加推理用量和等待。依据 [OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-sol) 与 [推理指南](https://developers.openai.com/api/docs/guides/reasoning)，查阅日期 2026-11-04。第三方兼容服务的实际行为由该服务决定。

等级按服务独立保存，同时用于连接测试、词典查词和文本翻译。Chat Completions 与 Responses 之间切换会保留等级；切换到其他原生协议或应用新的服务预设会恢复为「跟随服务」。Ollama、Anthropic 和 Gemini 原生协议不提供此选项，沿用各自原有请求行为。

服务拒绝思考参数或等级时，会保留错误详情，并对可识别的思考设置错误提示改回「跟随服务」。程序不会自动改级或重复请求；修改后可重新测试并保存。

## 查词与翻译

- **智能识别**：根据输入长度及标点判断查词或文本翻译，也可手动切换模式。
- **文本翻译**：选择原文、目标语言和风格，点击「开始翻译」，或按 `Ctrl + Enter`；结果逐步显示，期间可停止。
- **词典**：默认请求常用词性和简短译义，适合本地小模型。程序直接将文字排成词条，不要求模型生成 JSON 或完整词典资料。目标为中文但模型的释义只返回外文时会提示重试，不保存此次结果。
- **复制与收藏**：右侧顶部可复制完整结果，查询成功后可以收藏到生词本。
- **历史与生词本**：支持搜索、重新打开、取消收藏和删除。删除历史记录也会移除对应收藏。
- **外观**：支持浅色、深色及跟随系统，可在左下角或偏好设置切换。

AI 结果会标注生成来源，释义和音标不等同于专业词典的授权条目。当前单次最多输入 24,000 个字符；普通生成请求默认连续 10 分钟没有服务数据才超时，收到数据后重新计时，连接测试与测试识图仍为 90 秒。停止、截断或失败的生成不会作为完整记录保存。

### 为本地小模型选择词典内容

在「偏好设置 → 编辑 AI 服务 → 词典内容」中选择，必要时向下滚动：

- **简明词条（默认）**：优先生成一个常用译词及其词性，不生成音标、例句、搭配或近义词。右侧使用 `v.`、`n.`、`adj.`、`adv.` 等缩写配合译义显示，不重复左侧原词，也不显示编号；复制结果只包含词性和译义。模型未提供可识别的词性、或照抄一串词性选项时留空，不猜测补齐。旧服务配置默认使用此项；旧的简短释义历史同样不重复原词，不自动补发请求生成词性。已有完整词条历史仍可打开、复制和收藏。
- **完整词条**：优先请求 1–3 条短释义，音标、例句、搭配、近义词及用法提示均为可选内容，不要求模型填齐所有字段。收到完整的释义条目后先展示，期间显示「正在补全词条」。生成完成前不开放复制、收藏，也不保存历史；取消或连接中断会清除预览。

此项按服务独立保存，用于「词典」及「智能识别」判定为查词的请求；「文本翻译」和「测试连接」不受影响。切换接口协议保留选择，应用服务预设会恢复简明词条。简明词条不改变思考等级设置，每次查词只发送一次请求。

模型返回的格式不必完全一致：完整模式收到简短的「词性 + 译义」或纯译词时，也会排成简明词条；简明模式收到 JSON 时只提取词性和释义。结构化回答末尾的备注、例句等写错格式时，会保留前面已完整解析的释义及扩展项，不补写未闭合的字符串，也不额外请求 AI。无法解析出有效释义时提示重试，不把整串 JSON 当译文显示或保存。

两种词典模式均检查请求开始时所选的目标语言。例如输入「有趣的」、目标「英语」，应返回英文对应词。简明模式会去除精确匹配的「原词：」前缀及完全重复的译义。每条中文译义须含汉字；英文译义须含拉丁字母且不夹带汉字等其他文字。检查失败或没有有效译义时，不保存到历史。

两种模式均只请求当前选定的 AI 服务，不引入离线词库、不自动转用其他服务，也不自动重试。小模型仍可能误判词性、误译、多义词解释不全或误判生僻词；上述文字检查不能区分所有语言，也不能验证词性或释义事实是否正确。需要保留外文拼写的专有名词可使用「文本翻译」。

### 查看等待时间

生成中会显示当前进度。生成成功后，结果下方显示从发起请求到处理完响应的用时，包含网络、服务排队和模型推理。打开历史、清空或查看示例会清除计时。分段显示依赖服务持续发送正文。

## 截图 OCR 与 AI 识图取字

1. 点击工作台右上角「截图取字」，或右键托盘图标选择「截图取字」。
2. 译意会暂时隐藏，拖动框选文字区域，松开鼠标完成截图；`Esc` 或右键取消。多屏环境可在任意一块屏幕内框选，单次不跨屏。
3. 选择 **本地 OCR** 或 **AI 识图取字**。本地模式框选后自动运行 RapidOCR；AI 模式选择视觉服务并点击「开始识别」，只返回图片中的原文，不自动翻译。
4. 两种方式共用可编辑的原文框。校对后可「复制原文」，也可「放入原文」带回工作台，或点击「翻译文字」。复制和翻译均使用当前修改后的内容；单词仍按智能识别进入词典模式。
5. 本地识别使用 **RapidOCR · 中英文**，无需安装语言包或选择识别语言。本地识别不满意时，可在同一张图上切换 AI 再识别；切换本身不会发送请求。两种方式分别保留原文及修改。点击「重新识别」成功后替换该方式的旧结果，失败或取消保留旧结果；关闭弹窗或重新截图则清除两份内容。

本地 OCR 不需要视觉模型或 API Key，不上传截图。仅框选区域会临时保存以供识别，完成或取消后删除；原图留在弹窗内供切换模式，关闭时清除。文字不会自动请求 AI，点击翻译才发送给当前服务。识别最多等待 60 秒，可随时取消；放入工作台的文字仍受 24,000 字符限制。

**AI 识图取字**要求模型保留原文语言、大小写、标点和段落，不翻译、不解释、不改写；无法辨认的位置用 `[unclear]` 标记。结果逐步显示，生成中暂不可编辑或通过按钮复制、翻译。识别失败或取消时丢弃本次未完成内容，恢复此前的原文和修改；仍需对照截图校对模型可能读错的内容。

视觉服务独立于工作台选择。弹窗下方「翻译使用」显示工作台当前服务和模型，可选择目标语言；点击「翻译文字」才将校对后的纯文本送给该服务，不再次发送截图。AI 识别后再翻译共两次请求；仅识别或复制原文只需一次，两个步骤都可使用本地模型。识别不写入查询历史，进入工作台后成功完成的翻译按普通查询保存。

添加或编辑 AI 服务时，可点击 **测试识图** 检查模型是否读出了随机图片文字。普通「测试连接」通过并不等于支持视觉。llama.cpp 使用 Chat Completions 协议、`http://127.0.0.1:8080/v1` 地址，并在服务端加载匹配的 `--mmproj`。保留自己的思考等级设置；测试、识别与翻译不会自动换模型或重试。

视觉图片限制为每边不超过 4096 像素、总像素不超过 1200 万、PNG 不超过 8 MiB。超出会提示缩小截图。点击发送后，图片只提交到所选地址。若选云端服务，将使用其图片处理能力及相应额度。

截图支持图片、扫描版 PDF 等无法直接划词的画面。清晰度、字体、语言及复杂排版会影响识别结果，使用前可直接在弹窗中修改。

## 拖入文档文件

从资源管理器将一个 `.txt`、`.docx`、`.pptx` 或 `.pdf` 文件拖入主窗口，程序会进入对应页面。支持中文、空格路径和大小写扩展名。旧版 DOC / PPT 请先另存为 DOCX / PPTX。

拖入 TXT 沿用「文档翻译 → TXT」中的编码选择；Word、PPT 和 PDF 在本机解析并恢复已有任务。打开文件不会自动调用 AI，核对原文后再点击翻译。正在处理对应文档时需先暂停或等待完成，校对及设置弹窗打开时暂不接收拖入。

TXT 有尚未导出的译文时，更换文件会显示「取消」「直接更换」「导出后更换」。选择导出后更换时，取消保存或保存失败都会保留当前文档；不能用当前译文覆盖原文件或即将导入的文件。导出部分译文后继续生成的新内容仍会触发保护。按钮导入与拖入共用这些规则。PDF 切换前保存当前任务进度，重新打开原文件可继续。

## TXT 文档翻译

1. 打开左侧「文档翻译 → TXT」，选择编码后点击「导入 TXT」或拖入文件。默认自动识别带 BOM 的 UTF-16，否则按 UTF-8 读取；旧式中文文件可手动选 **GB18030 / GBK**，无 BOM 的 UTF-16 请显式选择字节序。编码改变后需重新导入。
2. 核对原文预览，选择 AI 服务、原文语言、目标语言和风格，点击「开始翻译」。导入和预览不会请求模型。
3. 程序按行与句子边界分段，单段最多约 1,000 字符，每段顺序请求一次模型，保留换行和空行。进度显示已完成段数，当前段会逐步预览；总段数可在开始前查看。
4. 点击「停止」保留已完成段落，当前未完成段不加入已完成译文；点击「继续翻译」重译这一段并继续。服务报错会停止，不自动重试或切换模型。
5. 全部完成后点击「导出 TXT」。暂停或失败后也可「导出已完成部分」，默认文件名带 `.partial.txt`，不能作为完整译文。导出为 UTF-8，保留原文件的常用换行形式，禁止覆盖原文路径。

单个文件最多 **2 MiB、20 万字符、500 段**。长文本不适合词典模式，始终按文本翻译处理；继续沿用任务开始时的服务、模型、API Key、思考等级、语言和风格。修改配置不会改变进行中的任务；需要采用新设置时，先停止并导出需要保留的内容，再点击「重新翻译」清空进度，重新开始。

文档翻译期间暂停工作台查询和连接测试，避免向本地模型同时提交多个任务。TXT 翻译不加入查询历史；任务进度暂存在内存中，退出程序前请导出。关闭窗口到托盘会继续翻译，托盘「退出译意」才会结束程序。Word / PPT 使用同页的独立标签，PDF 使用侧栏的独立入口。

## Word / PPT 文档翻译

1. 在「文档翻译 → Word / PPT」打开或拖入 DOCX / PPTX。选择模型、语言和风格后手动开始翻译；无需安装 Office。
2. 左侧选择段落，右侧对照原文、修改译文并点击「保存校对」。支持保留原文、单段重译、暂停续译，进度与草稿保存在本机，重开原文件可恢复。
3. 「另存译文」保存为新的同格式可编辑文件，并生成 `.issues.txt` 校对清单。未完成段落保留原文。Word 可能重新分页；PPT 可设置最小字号，溢出估算和复杂内容会列出提示。
4. 文档中的图片可通过「图片取字」手动识别、校对、复制，再单独翻译；原图保留。图表关联的工作簿、数据以及自动域、修订内容保留原样。
5. 可选设置已安装的 LibreOffice `soffice.exe`，生成 PDF 版式预览。段落对照及原格式导出不依赖此组件。

恢复已有 Word / PPT 任务时，顶部语言、风格和服务显示该任务实际使用的设置。更改设置会先提示清除当前译文和校对草稿；需要保留时先取消并另存译文，确认切换后再点击「开始翻译」。取消不会修改旧任务；切换不会自动调用模型。

全部段落处理完成后，主按钮显示可点击的「重新翻译」。确认后按界面显示的设置从第一段重新翻译；取消保留旧结果与草稿。需要改成英语时，先选择「英语」并确认切换，再点击「开始翻译」。

支持范围与操作细节见 [Word / PPT 翻译说明](Office翻译-0.11.0.md)。

## PDF 翻译

1. 打开左侧「PDF 翻译」，点击「打开」选择文件，也可直接将 PDF 拖入主窗口。导入、解析、翻页和预览在本机处理。
2. 在「翻译设置」中选择翻译模型、扫描页识图模型和清晰度。主工具栏显示当前任务实际使用的模型；已有译文任务沿用首次的模型、目标语言与风格。
3. 选择目标语言与范围，默认当前页。文字页点「翻译」，扫描页点「识别并翻译」。整篇任务会按页自动完成文字提取、必要的识图和翻译；识图发送区域图片，翻译发送段落文字，不上传整份 PDF。
4. 两页同步滚动，可输入页码跳转和缩放。「更多 → 展开阅读」收起侧栏。正文、标题、图片及分隔线保留原位置。
5. 点击右页段落校对、复制原文与译文，也可调整字号、样式、位置及背景。底部点击「待校对」查看页码与原因，再选择问题定位段落。
6. 运行时点「暂停」，之后点「继续」。范围、完整结果和进度会保存；重开同一文件后由用户继续，不自动发送请求。进行中切换阅读页码不会改变任务范围。
7. 「更多 → 重译当前页」暂存整页的新结果，全部成功后一次替换；失败或暂停保留整页旧译文，其他页不变。暂停后修改原文或译文，会在继续时重新生成该页的新结果。单段也可以在校对弹窗中重译。
8. 「更多 → 清空全书译文」需要确认，会清除译文和任务模型快照，保留已识别、校对的原文。需要换模型或目标语言时先导出要保留的内容，再清空并开始。服务被删除或配置已改变时会提示恢复原设置；API Key 不写入 PDF 任务缓存。
9. 点「导出」另存，译文嵌入中文字体，可复制、搜索。只完成部分内容时会提示；未译内容和无法安全替换的区域保留原文，并附检查清单。原 PDF 不变；导出失败或取消时，已有目标文件保持完整。

PDF 自动翻译遇到异常文字、控制标记、代码或表格数字校验失败时，会保留原模型和思考等级，自动再试 2 次。普通翻译仍失败时，该段保留原文并记入待校对，继续处理后文；连续 3 段均重试失败则暂停，避免持续消耗请求。单段手动重译仍由用户明确发起；网络或 HTTP 错误会暂停。

如果还有失败段落，遍历结束后会显示剩余段数，不会标为全书完成；点击「继续」只补未完成段落。在「待校对」定位段落，打开「查看失败返回」可只读查看或复制最近一次被拒绝的内容，它不会写入译文。当前页重译在重试耗尽时保留整页旧译文，继续后再完成整体替换。

底部显示当前任务进度。「已完成」表示所选范围内的翻译已结束，请通过「待校对」查看排版和内容问题。主预览为页面图像，选择文字请进入校对弹窗，或在导出的 PDF 阅读器中操作。

模型推理或排队较久时，可在「翻译设置 → 无响应等待」中选择 5 / 10 / 20 / 30 / 60 分钟，默认 10 分钟，设置会保存。每段请求收到服务数据时会重新计时。运行中可随时暂停，调整等待时间后继续，沿用原任务的模型、思考等级和完整进度。

HTTP 408 / 504 / 524 表示服务端或网关结束了等待，需要检查服务端的限制。本地 PDF 解析、渲染与导出使用独立的 90 秒无进展保护。

文字页支持横排单栏、多栏和表格。打开后分批解析，已解析的页面即可阅读和校对。「更多」中可暂停或继续解析，也可打开「结构校正」调整栏、单元格、阅读顺序及跨页表头。任务按页存入 SQLite，兼容已有的 SQLite 和 JSON 任务数据。

扫描件先在本机定位文字区域，再由所选 AI 分段识别。主翻译按钮自动衔接识别与翻译。希望先校对原文，可在「更多」中选择「仅识别当前页」或「批量识别」。重新识别整页成功后才替换，取消或失败保留旧内容。「整页文字」查看并复制全部原文或译文，「上次草稿」保存上次识别前的内容。有坐标的内容请通过段落校对修改。

小字可在「翻译设置」中选「高清」；「更多 → 框选取字」生成独立识别结果。扫描图片背景可选自动清理、局部背景修复、底色译文框或原图对照；局部修复需先保存并检查右页，再确认。复杂照片修复可能留痕，可改用底色框或原图对照。竖排、旋转、复杂公式、不规则图文环绕及手写内容仍需人工检查。

导出前会检查全书。界面「导出」会生成可用结果：未通过排版、数字或其他内容校验的区域保留原文，已经保存的译文不会删除。导出成功后若有问题区域，会明确显示页数与区域数；同目录的 `<文件名>.pdf.issues.txt` 列出页码、段落 ID 和原因。可在「待校对」定位修改后再次导出。清单写入失败会单独提示，已生成的 PDF 不会被误报为未生成。

大文档导出分批暂存，目标磁盘需留出临时空间。单页复杂度、异常对象、渲染尺寸与段落长度保护适用于各类文档。 [PDF 版式与导出](PDF版式与导出.md)

## 窗口与滚动

- 默认窗口为 1000 × 680，最小为 900 × 600；小窗口会收起输入区的示例说明，保留编辑空间。
- 窗口标题栏与界面融合；右上角依次为最小化、最大化 / 还原和关闭。
- 按住窗口顶部空白区域可拖动窗口，双击该区域可最大化或还原。
- 在普通窗口状态下，拖动窗口边缘或四角可调整大小；最大化时为显示器的工作区域，保留任务栏空间。
- 输入框、翻译结果、设置、服务弹窗、历史和生词本统一使用滚动条；滚动到边界后直接停止，反向滚动立即响应。支持鼠标滚轮、触控板和拖动滚动条。

## 托盘、全局快捷键与划词

这些功能可在「偏好设置 → 桌面与划词」调整，开关和快捷键保存在本机。

| 功能 | 默认行为 |
| --- | --- |
| 关闭窗口 | 隐藏到系统托盘，继续响应划词和快捷键。关闭此选项后，关闭窗口会退出程序。 |
| 打开工作台 | `Ctrl + Alt + Y`，隐藏或最小化时也能唤起，保留此前最大化状态。 |
| 查询选中文字 | 在其他应用中选中文字，再按 `Ctrl + Alt + D`。 |
| 划词浮标 | 拖动划选或双击选词后，在文字附近显示「查词」。**点击才请求 AI**，不会自动查询。 |

- 点击托盘图标打开窗口；右键可打开偏好设置、切换「划词浮标」和退出译意。图标可能位于 Windows 托盘折叠区域。
- 关闭后再双击同一数据目录下的译意，会打开已有窗口，不重复启动后台实例。
- 快捷键框需要先点击，再按下新的组合键，最后点击「保存快捷键」。支持 Ctrl、Alt 或 Win 配合字母、数字或功能键；F12 被 Windows 保留。两个动作不能使用同一组合键。若被其他应用占用，将提示错误；修改失败时保留原先已注册的快捷键。
- 浮标不抢走原应用的焦点，不读取或修改剪贴板。点击别处、切换应用、暂停划词或等待约 8 秒后收起。
- 划词查询使用当前选择的 AI 服务、词典内容设置和目标语言，并切换到「智能识别」：单词按词典查询，句子按文本翻译。已有请求正在生成时，不中断或额外提交新请求。
- Windows 文字选择接口不覆盖所有应用。某些浏览器页面、PDF、游戏和自绘界面可能不显示浮标；截图、扫描版 PDF 不支持直接取词。
- 全局取词快捷键会先尝试文字选择接口，必要时模拟 `Ctrl+C`，只使用本次复制得到的新文本，并尽量恢复原剪贴板各格式。如果取词期间其他应用更新了剪贴板，会取消本次查询并保留新内容。密码框不取词，超过 24,000 字符时需要缩短选择。
- 普通权限的译意无法保证读取以管理员权限运行的软件。无法取词时可手动复制，再回译意粘贴查询。
- 浮标本身不会发起网络请求；点击浮标或使用取词快捷键后，原文才会发送到当前配置的模型服务。所有模式都不会自动切换到云端服务或重试。

## 数据保存

默认目录为 `%LOCALAPPDATA%\Yiyi\Yiyi`，实际位置显示在「偏好设置 → 数据与隐私」。

- `settings.json` 保存偏好和服务配置，`desktop.ini` 保存桌面集成开关和快捷键。首次启动可读取原有 `settings.ini`。API Key 使用 Windows DPAPI 加密，与当前 Windows 用户关联。
- `history.sqlite` 保存查询历史和收藏。备份时先退出应用，再复制整个数据目录。
- `pdf-tasks` 保存 PDF 已完成段落的原文、译文和任务设置，以文件内容指纹区分。点击 PDF 页面「更多 → 清空全书译文」清除该文件的译文；退出程序后可删除该目录清理全部 PDF 进度，不影响源文件。
- 凭据复制到另一台电脑或另一 Windows 用户后可能无法解密，需要重新填写 API Key。
- 翻译内容会发送给当前选择的服务；配置为本机服务时由该服务处理。程序不自带遥测或云端同步。

## 常见问题

- **更新后仍是旧界面**：先在系统托盘（可能位于折叠区域）右键「退出译意」，再打开新版本文件夹里的 `Yiyi.WinUI.exe`。只关闭窗口会保留原后台实例。
- **快捷键不生效**：到「偏好设置 → 桌面与划词」确认已启用全局快捷键；若提示组合键被占用，改用其他组合并保存。两个动作不能设置相同组合。
- **选中文字后没有浮标**：确认「划词浮标」已开启；部分应用不提供可读取的选择，可尝试 `Ctrl + Alt + D`（或自定义取词快捷键），也可复制后在工作台粘贴。图片和扫描版 PDF 可使用「截图取字」。
- **本地 OCR 启动失败**：使用完整发行包，保留 `yiyi_ocr_worker.exe` 和 `ocr` 目录，无需安装系统语言组件。若未识别到文字，请缩小截图范围、选择更清晰的文字，再点击「重新识别」；也可自行切换 AI 识图取字。
- **TXT 乱码或编码不匹配**：选择正确编码后重新导入；常见旧中文文件选择 GB18030 / GBK。程序不会将损坏编码替换为乱码后继续翻译。
- **PDF 无法开始翻译**：在「翻译设置」中选择翻译模型与扫描页识图模型，再点击主翻译按钮；不支持的文字版式可用「更多 → 仅识别当前页」手动识别后重新排版。PDF 组件缺失时请使用包含 `pdf` 目录和 `yiyi_pdf_worker.exe` 的完整发行包。
- **PDF 等待模型超时**：默认允许连续 10 分钟没有服务数据。可暂停后在「翻译设置 → 无响应等待」延长，再继续原任务；保留当前模型和思考等级。HTTP 408 / 504 / 524 属于服务端或网关超时，需要检查服务端限制。
- **PDF 导出保留了问题区域原文**：导出成功提示及同目录的 `.issues.txt` 会列出未替换区域。点击橙框或待校对列表定位段落，调整区域、字号或措辞后「保存并排版」，再导出；清空某段译文会恢复该段原文。
- **无法连接**：确认服务已启动、端口和基础地址正确；本地模型是否加载完成。
- **401 / 403**：检查 API Key、账户及模型权限。
- **404**：核对接口协议、地址路径和模型 ID。
- **429**：检查额度或调用频率，稍后重试。
- **思考参数或等级不受支持**：编辑 AI 服务，将「思考等级」改为「跟随服务」后重试；不要用 `none` 代替省略参数。
- **响应中断或过长**：缩短原文、更换模型或重试。未完成结果不会加入历史。
